## Context và mục tiêu

Chạy nhiệm vụ bằng một phiên Codex thật trong container. Mỗi run độc lập; backend lưu input/output làm cơ sở nối 5 agent.

## Phạm vi triển khai

1. Runner nhận role/task/project/run IDs, working directory và context manifest. Gọi CLI bằng executable/argv thay vì nối shell từ ý tưởng người dùng.
2. Mỗi nhiệm vụ là session mới; không resume thread trước. Ghi session ID nếu CLI cung cấp, timestamps, stdout/stderr có giới hạn và execution status.
3. Lưu prompt, input refs, output Markdown/JSON/code và output envelope trong workspace đúng project; tạo Artifact version/hash/producer metadata bằng T02.
4. Validate file tồn tại, không rỗng, schema theo vai trò, đường dẫn/ownership và hash; exit 0 không tự hoàn thành task.
5. Timeout/cancel dừng process tree; không tự retry. Sinh trạng thái failed/timed_out/cancelled/invalid_output rõ ràng.
6. Có fake adapter cho tests, phân biệt rõ live/fake. Smoke thật chỉ khi Codex đã sẵn sàng và được người dùng cho chạy.

## Tiêu chí nghiệm thu

- [x] Hai lần chạy tạo phiên/context riêng và artifact refs không trộn.
- [ ] Một smoke thật trong container tạo file được đọc lại từ volume; report ghi CLI version và run ID.
- [x] Output thiếu/sai, timeout/cancel không vượt validator và không để lại process chạy ngầm.

## Ngoài phạm vi

Không scheduler tổng quát, resume session, auto-retry hoặc API streaming phức tạp.

## Bàn giao và kiểm chứng

Runner gọi exec mới với argv cố định, prompt/schema/manifest riêng; ghi session ID, validate output, timeout/cancel dừng process group. 6 tests runner dùng tiến trình fixture, gồm hai phiên riêng, exit 0 thiếu output, path sai, auth thiếu, timeout/cancel. Không có fixture provider trong app production. Một smoke model thật trong Docker chưa chạy theo yêu cầu người dùng; vì vậy chưa DONE.
