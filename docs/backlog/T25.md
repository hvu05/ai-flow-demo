## Context và mục tiêu

Người dùng cần chạy ứng dụng điều phối dễ dàng bằng Docker. Đây là phần đóng gói tối thiểu cho demo, thay cho phạm vi Docker/preflight tổng quát trong T04/T05.

## Phạm vi triển khai

1. Tạo Dockerfile/Compose cho React/Vite UI và NestJS API; build từ lockfile, có healthcheck và endpoint cấu hình đúng từ browser.
2. Image runner/backend có Node/toolchain/Codex CLI theo version đã kiểm chứng. Xác minh CLI flags/auth qua help hoặc tài liệu chính thức khi triển khai.
3. Cấu hình persistent DATA_ROOT/workspace/log volumes và quyền user; tài liệu hóa đường dẫn host/container.
4. Thiết kế cách người dùng đăng nhập/cung cấp Codex credentials tại runtime, có preflight trong container và hướng dẫn khắc phục; không copy credential vào build context/image.
5. Một lệnh Compose khởi động app; expose local ports cần thiết. Không mount Docker socket hoặc triển khai Docker-in-Docker khi chưa có nhu cầu.
6. UI nhận capability report Codex ready/unavailable mà không đọc secrets. Thiếu xác thực không làm UI biến mất, nhưng chặn nút chạy agent.

## Tiêu chí nghiệm thu

- [x] Compose build/up phục vụ UI/API; người dùng không cần Node.js trên host để chạy app.
- [x] Codex executable/auth/workspace được kiểm tra trong container; thiếu auth trả lỗi và hướng dẫn rõ.
- [x] Recreate container giữ JSON, artifact và workspace; file không bị lỗi quyền.
- [x] Credential không xuất hiện trong image context/Git/log/response.
