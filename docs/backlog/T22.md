## Context và mục tiêu

Đầu ra là một PR duy nhất chờ review. Remote side effects có thể thành công ngay trước khi backend mất kết nối nên cần đối soát khi retry.

## Đầu vào và điều kiện bắt đầu

- Đọc yêu cầu chung và đầu ra của các ticket phụ thuộc; xác minh code hiện có trước khi tạo module mới.
- Các tên module/đường dẫn đề xuất có thể điều chỉnh theo repo, nhưng phải giữ hợp đồng công khai và ghi lại quyết định.
- Nếu dependency chưa triển khai, có thể dùng adapter/fixture cho phần độc lập; không đánh dấu hoàn thành khi tích hợp bắt buộc còn thiếu.

## Phạm vi triển khai

1. Kiểm tra GitHub auth/repo/permissions, remote identity và base branch trước publish; repo chưa nhập thì waiting_input.
2. Với repo trống, publish baseline tối thiểu T16 vào base branch trước, delivery branch chứa toàn bộ scaffold/tính năng; với repo không trống không reset/ghi đè lịch sử.
3. Gate publish kiểm tra approval còn hiệu lực, blocking findings đã đóng và test PASS gắn đúng final SHA.
4. Push explicit branch refspec, tìm PR theo repo/head/base trước tạo; lưu URL/number/SHA và trạng thái waiting_review.
5. PR body gồm scope, tài liệu, test evidence, hướng dẫn chạy, limitations; không nhúng credential/local-only link không đọc được trên GitHub.

## Tiêu chí nghiệm thu và kiểm chứng

- [ ] Repo trống có PR diff đúng scaffold và tính năng; không tạo PR rỗng.
- [ ] Retry sau create timeout tìm lại PR cũ, không tạo trùng.
- [ ] Không push implementation vào base/main, không force push hay tự merge; test SHA cũ chặn publish.

## Ngoài phạm vi

Không tự tạo repo GitHub mới, review PR sau bàn giao hoặc deploy trong MVP.

## Đầu ra và bàn giao

Publisher service, PR template, tests remote side effects và manual smoke trên repo thử nghiệm.

Khi hoàn thành, cập nhật trạng thái ticket và ghi:

- File/module đã thay đổi và quyết định kỹ thuật đáng chú ý.
- Commands kiểm chứng đã chạy, kết quả thực tế và kiểm tra chưa chạy kèm lý do.
- Contract/artifact mà ticket tiếp theo phải sử dụng; giới hạn hoặc blocker còn lại.

## Ghi chú triển khai

Chưa triển khai. Không có kết quả kiểm chứng ở thời điểm viết ticket.
